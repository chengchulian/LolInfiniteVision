# 加载器资源

[返回首页](../../README.MD) · [构建与验证](../../docs/development.md)

此目录保存两种可供其他插件共用的现有加载器，项目不在此处编译加载逻辑。

| 文件 | 助手资源 | 部署文件名 |
| --- | --- | --- |
| `version.dll` | `IDR_LOADER` | `Game/version.dll` |
| `dinput8.dll` | `IDR_DINPUT8_LOADER` | `Game/dinput8.dll` |

两种文件作为独立资源嵌入 EXE。更换资源时需保持 Windows x64 PE 格式，并重新构建助手；CMake 已将两种 DLL 都列为资源生成依赖。

加载器识别使用完整内容比较。资源变更后，旧版同名文件可能被视为“已被其他 DLL 占用”，不会自动覆盖或删除。更新时需核实已有文件的用途，并验证插件目录约定及与其他插件共用的行为。

面向使用者的加载器选择、状态和清理说明统一见[使用指南](../../docs/usage.md)。
