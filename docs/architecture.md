# 架构说明

[返回首页](../README.MD) · [构建与验证](development.md) · [攻击范围实现](native-attack-range.md)

项目由部署助手和游戏内插件两部分组成。助手负责文件与配置；插件被加载后负责功能初始化和游戏内快捷键。

## 部署助手

| 模块 | 职责 |
| --- | --- |
| `installer/Assistant.cpp` | 原生 Win32 界面、目录选择、加载器状态刷新、按键捕获和操作入口。 |
| `installer/Deployment.cpp` | 路径检查、插件部署、加载器识别与独立操作、清理和失败回滚。 |
| `installer/Assistant.rc.in` / `resource.h` | 界面布局、控件编号、资源和版本信息。 |
| `installer/assets/` | version / dinput8 两种加载器的独立二进制资源。 |
| `tools/GenerateAssistantResource.cmake` | 将插件、默认配置、加载器和清单路径写入构建资源。 |

助手通过比较完整文件内容识别本项目加载器，不只依据文件名。不同内容的同名 DLL 记为占用，不计入本项目加载器数量，也不覆盖或清理。

`Install` 只更新插件 DLL 和 INI；`InstallLoader` 只写入所选加载器；`Uninstall` 只清理插件及配置；`RemoveLoader` 只清理选中的匹配加载器。界面和命令行使用相同的部署接口。

插件写入先在暂存目录生成文件，再逐一替换目标；失败时尝试恢复已替换的原文件。加载器写入采用独立暂存文件，提交时不覆盖检查后新出现的目标。清理先移动目标文件，移动阶段失败时恢复已移动的文件，再删除暂存文件。若恢复或删除失败，会报告失败及相关路径，不保证所有文件系统错误都能自动恢复。

## 游戏内插件

初始化和运行顺序：

1. DLL 入口保存配置路径并固定模块，延迟安排初始化回调。
2. 初始化回调读取初始状态、快捷键和控制台选项。
3. 扫描时间特征码，解析游戏时间地址，等待游戏时间大于零。
4. 查找游戏窗口，定位各项补丁和攻击范围事件入口，在窗口线程安装定时回调。
5. 窗口线程应用初始状态，持续处理快捷键；攻击范围开启时定期刷新原生事件。

| 模块 | 职责 |
| --- | --- |
| `src/dllmain.cpp` | DLL 入口、延迟初始化、读取配置和启动调度。 |
| `src/FeatureControls.cpp` | 游戏窗口与前台检查、初始状态、快捷键触发和功能切换。 |
| `src/Hotkeys.h` | 共用默认绑定、编码归一化、重复检查和按键边沿状态。 |
| `src/OpcodePatch.cpp` | 验证当前字节、应用或恢复补丁、刷新指令缓存并恢复页面保护。 |
| `src/GameTime.cpp` | 时间特征码定位、相对地址解析和就绪等待。 |
| `src/AttackRange.cpp` | 普通攻击范围的原生开启、隐藏事件与刷新节奏。 |
| `src/NativeOverlayBindings.cpp` / `AttackRangeSignatures.h` | 攻击范围指令特征码、唯一命中校验与引用解析。 |
| `src/OverlayEventPump.cpp` | 在游戏窗口所属线程安装消息钩子和定时回调。 |
| `src/Method.cpp` / `Memory.cpp` / `Constant.cpp` | 配置与日志、模块和特征码扫描、内存访问、补丁常量。 |

定时回调间隔为 30 毫秒。快捷键按前台状态与按键边沿判断，游戏内状态不会持久化。视距、防回弹和塔范围使用可恢复的指令补丁；攻击范围开启后每 750 毫秒派发原生开启事件，关闭时派发一次隐藏事件。

## 兼容性与验证边界

运行依赖游戏的模块布局及特征码。时间定位失败时无法进入功能初始化；某项补丁或攻击范围入口不可用时，会记录告警并跳过对应操作。攻击范围解析不依赖固定版本号、时间戳或模块 RVA，具体校验见[攻击范围实现](native-attack-range.md)。

离线测试覆盖定位、状态切换和部署行为。实际游戏中的加载、绘制及版本兼容性需要另行进入对局验证。
