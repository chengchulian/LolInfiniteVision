# 原生攻击距离事件

`attackRange` 控制游戏自带的普通攻击距离覆盖层，事件名为 `evtToggleShowOverlayAttackRange`。初始开关位于 `[Config]`，游戏内快捷键位于 `[Hotkeys]`；默认 Ctrl+F7，可在助手界面通过按键捕获修改。

## 定位与运行

`src/AttackRangeSignatures.h` 保存五组带通配符的指令特征码：派发入口、事件处理器、处理器的开关分支、本地玩家选择以及玩家表。派发入口和处理器在模块范围内要求唯一命中，其余特征码在处理器前 `0x200` 字节内要求唯一命中。

全局指针和玩家索引字段由匹配指令解析，未使用固定模块 RVA、PE 时间戳、版本号或预期镜像大小。保留模块范围检查；匹配缺失、重复或引用越界均记录告警并停用该功能，不影响其他功能开关。

`FeatureControls` 在游戏窗口线程启动 30 毫秒定时回调，处理快捷键及功能状态。攻击范围开启时每 750 毫秒刷新一次原生事件，关闭时发送一次隐藏事件并停止刷新。游戏时间、本地玩家、HUD 与派发器未就绪时延后处理。

同步派发开启事件期间，临时将原生处理器的 `74 05` 改为 `EB 05`，选择 `mov r9b,1`；关闭事件使用 `EB 00`，选择 `xor r9b,r9b`。派发结束后在 finally 中恢复 `74 05` 和页面保护，不再永久改成始终开启。异常或校验失败时停止该功能，避免继续调用不可靠入口。

事件参数使用入口读取的 MSVC x64 字符串布局。没有更改原生处理器的玩家与句柄检查，不直接写 overlay 列表项，圆圈仍由游戏绘制。模块在异步初始化前固定，防止回调存续期间被卸载。

## 离线复核

保留的 `tools/AnalyzeAttackRangeDump.py` 从生产头文件读取特征码，检查映射布局 dump 的唯一命中和 RIP 引用，不打开进程、不执行游戏函数、不修改 dump：

```powershell
python tools/AnalyzeAttackRangeDump.py "<映射布局 dump 路径>"
```

`native-attack-range-offline` 使用自建镜像与测试窗口，检查跨页定位、缺失或重复命中、引用解析与越界拒绝、事件参数布局、窗口线程派发、初始关闭、重复开启、关闭隐藏、重新开启、指令恢复及停止回调。快捷键测试另检查修饰键、长按去重及前台切换。

离线测试不能证明实际游戏中的显示效果，仍需进入对局验证。
