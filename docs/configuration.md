# 配置参考

[返回首页](../README.MD) · [使用指南](usage.md)

## 读取位置与生效时间

插件从自身 DLL 所在目录读取 `LolInfiniteVision.ini`，默认位置为 `Game/load/LolInfiniteVision.ini`。配置在插件加载后的初始化阶段读取，修改文件后需要重新启动游戏进程。

仓库根目录的 INI 是默认模板：构建时复制到 DLL 输出目录，并嵌入助手。修改模板会影响后续构建；修改已部署游戏目录中的配置会影响下一次游戏启动。

助手重新写入插件时，更新四项初始开关和快捷键，保留已有的 `console` 及额外设置。配置缺失或某个键缺失时，使用对应的代码默认值。

## 默认配置

```ini
[Config]
console=0
visionSwitch=1
attackRange=1
antiRecoil=1
towerRange=1

[Hotkeys]
visionSwitch=629
attackRange=630
antiRecoil=631
towerRange=632
```

## 功能初始状态

`[Config]` 中四项功能的默认值均为 `1`；`0` 表示初始关闭，非零表示初始开启。

| 配置键 | 功能 | 默认快捷键 | 关闭时的行为 |
| --- | --- | --- | --- |
| `visionSwitch` | 无限视距 | Ctrl+F6 | 恢复视距补丁的原始指令字节。 |
| `attackRange` | 普通攻击范围 | Ctrl+F7 | 派发原生隐藏事件，停止常显刷新。 |
| `antiRecoil` | 视距防回弹 | Ctrl+F8 | 恢复防回弹补丁的原始指令字节。 |
| `towerRange` | 防御塔范围 | Ctrl+F9 | 恢复塔范围补丁的原始指令字节。 |

EXE 中的开关决定每次进入游戏的初始状态。游戏内通过快捷键切换后的状态不写回 INI，下次进入游戏仍使用配置的初始状态。

## 快捷键设置

在助手中点击对应输入框，直接按下所需按键即可捕获，支持 Ctrl、Alt、Shift 组合；按退格键清空绑定。不同功能不能设置相同组合，清空后该功能不响应快捷键，初始开关仍然有效。

快捷键只在游戏窗口位于前台时响应。长按只切换一次，松开后可再次触发；按住功能键后补按修饰键、或按住功能键切回游戏，不会额外触发。

手动编辑 `[Hotkeys]` 时使用以下整数编码：

```text
配置值 = Windows 虚拟键码 + 256 × 修饰键值
修饰键值：Shift=1，Ctrl=2，Alt=4，组合时相加
```

| 绑定 | 配置值 |
| --- | --- |
| 不绑定 | `0` |
| Ctrl+F6 | `629` |
| Ctrl+F7 | `630` |
| Ctrl+F8 | `631` |
| Ctrl+F9 | `632` |
| Ctrl+Shift+F6 | `885` |

缺少 `[Hotkeys]` 的旧配置使用默认绑定。非法数值、单独的修饰键和鼠标键会被禁用；手动编辑造成重复绑定时，所有重复项均禁用，其他项继续生效。

## 开发者选项

`[Config] console` 默认 `0`，不在 EXE 界面中显示。需要查看扫描地址、功能状态和失败告警时，将已部署配置中的 `console` 改为 `1`，再重新启动游戏进程。

再次写入插件会保留该选项。关闭调试窗口可将其改回 `0`，下次启动游戏时生效。
