# 使用指南

[返回首页](../README.MD) · [配置参考](configuration.md)

## 首次部署

1. 运行 `dist/无限视距助手.exe`，按系统提示授予管理员权限。单文件助手已内嵌插件、默认配置和两种加载器，无需安装 Python 或另外携带 DLL。
2. 退出游戏进程，可以保留英雄联盟客户端。
3. 点击“选择目录”，选择包含 `League of Legends.exe` 的 `Game` 目录或其上一级安装目录；也可使用“自动查找”。
4. 查看加载器状态。无加载器时，选择 `version.dll` 或 `dinput8.dll`，点击加载器栏中的“写入加载器”。
5. 设置功能的初始开关，点击快捷键输入框并直接按键绑定，再点击“写入视距插件”。
6. 进入对局，使用配置的快捷键切换功能。默认快捷键见[配置参考](configuration.md)。

“写入加载器”与“写入视距插件”是独立操作。只写入插件不会自动添加加载器；“写入完成”表示文件部署成功，游戏中的实际效果仍需进入对局验证。

## 加载器状态

加载器栏位于游戏目录和功能开关之间。选择或修改目录、执行写入或清理后会刷新状态；窗口打开期间每两秒自动刷新。

| 检测结果 | 界面提示与处理方式 |
| --- | --- |
| 没有本项目加载器 | 显示“无加载器，视距插件不生效”。选择一种加载器并单独写入。 |
| 只有一种本项目加载器 | 显示当前的 `version.dll` 或 `dinput8.dll`；通过目录选择载入配置时会选中检测到的类型。 |
| 两种本项目加载器同时存在 | 显示“存在多个加载器”。选择多余的一种并清理，只保留一种。 |
| 同名文件与内置加载器不同 | 显示“version.dll 加载器已被其他 DLL 占用”或“dinput8.dll 加载器已被其他 DLL 占用”。该文件不计入本项目加载器数量，写入和清理时均保留。 |

只有内容与对应内置资源一致的文件才会识别为本项目加载器。两个同名文件都被其他 DLL 占用时，分别显示占用提示，不显示“存在多个加载器”。只有一个名称被占用时，可选择另一个未被占用的名称写入。

内容相同的加载器会直接复用。切换加载器类型时，先清理原来的本项目加载器，再选择另一种写入；助手会阻止新增第二个本项目加载器。

## 更新与清理

写入和清理前都需要退出游戏进程。

| 按钮 | 位置 | 操作范围 |
| --- | --- | --- |
| 写入加载器 | 加载器栏 | 将选中的一种加载器写入游戏目录。 |
| 清理加载器 | 加载器栏 | 只移除选中且内容匹配的加载器，保留插件和配置。 |
| 写入视距插件 | 窗口底部 | 更新视距插件 DLL、初始开关与快捷键，保留开发者选项和额外配置。 |
| 打开插件目录 | 窗口底部 | 打开插件目录；目录尚未创建时打开游戏目录。 |
| 清理插件 | “打开插件目录”右侧 | 只移除视距插件 DLL 和同目录配置，保留加载器及其他插件。 |

插件目录还有其他 DLL 时，助手会阻止清理可能共用的加载器。需要移除本项目时，可先使用“清理插件”，保留共用加载器。重复清理已经移除的目标会直接成功。

更新功能开关或快捷键后，点击“写入视距插件”，下次启动游戏进程时生效。手动修改 INI 的方式见[配置参考](configuration.md)。

## 文件位置

默认部署结果如下，加载器二选一：

```text
Game/
  League of Legends.exe
  version.dll 或 dinput8.dll
  load/
    LolInfiniteVision.dll
    LolInfiniteVision.ini
```

如果游戏目录已有 `load.ini`，助手沿用 `[Config] LoadPath` 指定的游戏目录内相对子目录。例如 `LoadPath=plugins\custom` 会将插件和配置放入 `Game/plugins/custom/`。绝对路径、越过游戏目录的路径和游戏根目录本身不会被接受。

与其他插件共用加载器时，插件可以放在同一个插件目录。助手只更新或清理自己负责的目标文件。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 自动查找未找到目录 | 使用“选择目录”，选择 `Game` 目录或其上一级安装目录。 |
| 插件写入完成但提示无加载器 | 在加载器栏单独执行“写入加载器”。 |
| 加载器被其他 DLL 占用 | 保留该文件；另一种名称未被占用时可使用另一种加载器。 |
| 清理加载器提示仍有其他 DLL | 这些插件可能共用加载器；仅清理本项目时使用“清理插件”。 |
| 提示游戏正在运行或文件被占用 | 退出游戏进程，再执行写入或清理。 |
| 修改配置后未变化 | 重新启动游戏进程；快捷键只在游戏窗口位于前台时响应。 |
| 文件齐全但某项功能仍未生效 | 按[配置参考](configuration.md)开启控制台查看定位或补丁告警；构建与离线测试不能代替游戏内验证。 |
